## 3. 결정 사항과 이유

- 재처리: failed·no_text(그리고 섹션 없는 ready·indexed) → `needs_upload=true`(상태 유지, 화면 "다음 동기화 대기"). ready·indexed → 대기 중인
  index·embed 작업을 done으로 정리하고 `index` 작업 등록(Worker가 sections에서 재청킹, 임베딩 재사용), 상태는
  `extracting`("처리 중")으로. queued·extracting·embedding·meta_only → 409 `not_reprocessable`.
- 영구 삭제는 `app/ingest/purge.py`의 `purge_documents(session, ids, reason=…, mask=None)`로 T13·T14가 재사용.
  인용 가림: messages.citations에서 해당 document_id 항목의 snippet을 "삭제된 문서"로, `deleted: true` 추가(경로는 둠).
- 상세 링크: `/documents/{id}?loc=<location JSON>` + react-router state로 저장된 인용(경로·수정일·구절)을 넘김.
  삭제(404)·변경(인용 mtime ≠ 문서 mtime)이면 안내 + 저장된 구절 표시.
- "이 문서 요약": `/c/new`로 state `{summarize:{documentId, filename}}` 넘기면 ChatView가 한 번 보냄.
- 실패 안내 문구는 웹(`features/documents/status.ts`)에 TRD 3.4 표 그대로.
