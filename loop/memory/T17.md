## 3. 결정 사항과 이유

- 빌드 컨텍스트는 저장소 루트(`context: ..`), 루트 `.dockerignore` 하나로 제외 관리.
- backend 이미지: python:3.12-slim-bookworm + uv, 편집 가능 설치(/app/backend 그대로) → config.REPO_ROOT=/app, alembic.ini·kiwi 사전 경로 유지.
- PG17 클라이언트는 PGDG apt 저장소, age는 Debian 패키지.
- 같은 태그를 여러 서비스가 동시에 build하면 'already exists' 충돌 → build는 api에만, migrate·worker는 image + pull_policy: never.
- DB 조정값: deploy/postgres/tuning.conf를 /etc/postgresql/tuning.conf로 마운트, initdb 스크립트가 postgresql.conf에 include_if_exists 추가(첫 초기화 때만).
- POSTGRES_USER/PASSWORD/DB는 compose 변수 치환(--env-file .env, 기본 rag) → db와 DATABASE_URL(@db:5432) 공통.
- test_env_example: Settings 필드 + TRD 12.1 표 첫 열 변수가 .env.example에 있는지.
- SSE 경로: POST /api/conversations/{id}/messages → nginx 정규식 location에서 proxy_buffering off.
