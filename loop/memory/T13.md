## 3. 결정 사항과 이유

- 범위 제외 삭제 대상 = "현재 범위 안이던 문서 중 새 범위 밖"(이미 범위 밖인 문서는 건드리지 않음).
  E2E DB에 다른 허용 폴더로 넣은 문서가 남아 있어, 저장할 때 그것까지 지우면 다른 spec이 깨지기 때문.
- 보류 삭제 승인: sync_config에 승인 시각·대상 실행 ID 저장 → 다음 manifest 판정에서 대량 삭제 보호를 건너뛰고
  승인을 비움(판정 결과와 무관하게 한 번만). 보류 경로 전체 목록을 저장하지 않으므로 TRD대로 "다음 실행에서 적용".
- /sync/status·/sync/held-deletions/apply는 웹 세션 라우터(app/api/sync_web.py). /sync 접두사 Agent 라우터와 경로가 겹치지 않음.
- 하루 넘음 경고는 서버가 계산(stale.sync, stale.backup) → E2E page.clock과 서버 시각 불일치 방지.
- 최근 백업: 백업 생성은 T14 범위 → 지금은 last_backup_at=null(“백업 기록 없음” + 경고 배지).
- Windows 판정은 navigator.userAgent에 "Windows" 포함. E2E는 test.use({userAgent: Windows UA}).
