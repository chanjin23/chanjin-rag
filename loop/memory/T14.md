- 외부 명령은 설정 `BACKUP_PG_DUMP_CMD`·`BACKUP_AGE_CMD`(JSON 목록, 기본 ["pg_dump"], ["age"])와

  (WSL에 pg_dump·age 없음).
- 백업 폴더 `BACKUP_DIR`(기본 저장소 var/backups). SHA-256은 생성 때 `.sha256` 옆 파일로 저장, 없으면 계산.
- `last_backup_at` = 백업 폴더에서 가장 새 파일의 mtime.
- 로그: 서버 `backup.downloaded`(파일 내려줄 때), Agent `agent.backup.downloaded`.
- Agent 백업 폴더: `RAG_AGENT_BACKUP_DIR`, 없으면 Windows `C:\Chanjin\dev\backup`, 그 밖 `<agent home>/backup`.
