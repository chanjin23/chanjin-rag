## 3. 결정 사항과 이유

- ParadeDB 이미지는 `paradedb/paradedb:0.26.5-pg17`로 고정(2026-11-04 배포, TRD의 PG17). 컨테이너 프로젝트 이름 `chanjin-rag-test`.
- init SQL은 `/docker-entrypoint-initdb.d/` 하위 폴더가 무시되므로 파일 단위로 마운트. healthcheck는 `-h 127.0.0.1`(초기화 중 임시 서버는 TCP 미개방)로 확장 2개 존재 확인.
- DB 픽스처는 psycopg 3 동기 연결(세션 1개) + 테스트마다 `transaction(force_rollback=True)`. SQLAlchemy async 세션 픽스처는 T01에서 추가.
- `TEST_DATABASE_URL`은 SQLAlchemy 형식(`postgresql+psycopg://rag:rag@127.0.0.1:5433/rag_test`)이 기본. psycopg에는 `to_libpq_url`로 바꿔 넘김.
- `.env`는 `REPO_ROOT/.env`(config.py 기준 parents[3])로 고정. 프로세스 환경 변수 `APP_ENV=test`면 `.env`를 읽지 않고, 검증기가 NVIDIA 키를 비우며 `PROVIDER=nvidia`면 오류.
- `PROVIDER` 기본값은 `nvidia`(운영). 테스트(conftest 맨 위)·E2E는 `APP_ENV=test`, `PROVIDER=fake` 강제.
- `EMBED_BATCH_SIZE` 기본값을 TRD 12.1대로 32→1로 바꿈.
- Fake 임베딩은 토큰 feature hashing(blake2b) → 단위 벡터. passage/query 같은 공간이라 검색 테스트에 쓸 수 있음. Fake LLM은 `rules`(부분 문자열→답변), 없으면 `가짜 답변: {질문}`, 공백 보존 단어 조각으로 스트리밍, `calls` 기록. Fake 재정렬은 질문 토큰 겹침 비율.
- verify.sh: 테스트 DB 단계는 1/5(uv sync) 뒤, pytest 앞에 추가. `TEST_DATABASE_URL`을 미리 주면 컨테이너를 띄우지 않고 그 DB 사용. 컨테이너는 재사용을 위해 끝나도 내리지 않음. `SAMPLE_DOCS_DIRS`가 있으면 pytest 뒤에 `pytest -m samples` 단계 추가.
- E2E 백엔드 env: `APP_ENV=test`, `PROVIDER=fake`, `LOG_QUERY_TEXT=true`, `LOG_FORMAT=json`, `LOG_FILE`, `DATABASE_URL=TEST_DATABASE_URL`(기본 5433 URL).
- E2E에서 `app.started` 로그로 provider를 확인하려 했으나, `globalSetup`이 웹서버 기동 **뒤에** 로그 파일을 비워 그 줄이 사라짐 → 단언 제거(설정은 pytest `test_config.py`로 검증). 기존 chat.spec.ts는 원래 내용 그대로 통과.
- TRD 수정(구현에 맞춤): 2장 `.env` 위치, 4장 `deploy/compose.test.yaml`·`test-db-init/`, 12.1에 `APP_ENV`·`PROVIDER`·`DATABASE_URL` 행, 14장 통합 행 보강 + `실제 문서`(samples) 행 추가. PRD와 충돌 없음.
- Provider 팩토리는 T03 범위라 만들지 않음. chat.py도 아직 스텁(Provider 미연결).
- 로그 정책: `chat.message.received`는 항상 `length`, `LOG_QUERY_TEXT=true`일 때만 `text`. `app.started`에 `provider`, `log_query_text` 기록.
- 테스트 로그 캡처는 `structlog.testing.capture_logs`(설정 목록을 제자리 수정하므로 캐시된 로거에도 동작).
- pytest `addopts = ["-m", "not samples"]`; 명령줄 `-m samples`가 뒤에 와서 우선. samples 단계용 테스트 `test_samples.py::test_sample_docs_dirs_have_documents`(개수만 확인) — 없으면 `-m samples`가 종료 코드 5.
