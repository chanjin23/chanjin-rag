# T11 · 채팅 화면: 대화 관리, 출처 패널, 인용, 피드백

## 목표

채팅 화면을 PRD·TRD의 사용자 경험대로 완성한다. 대화 목록과 관리, 출처 패널, 인용 칩, 안전한 마크다운, 오류·재시도, 색인 범위 줄, 답변 피드백까지.

## 근거

- PRD F-08, F-10, F-11, F-12, F-18(색인 범위 표시), 7장(외부 이미지·링크 차단), TRD 5.3(`conversations`, `feedback`), 8.3, 9.1(채팅, 공통 화면 상태), 9.2(답변 렌더링, 로컬 경로, 입력 보존, 접근성)

## 구현 항목

- [ ] API: `GET·POST /conversations`, `GET·PATCH·DELETE /conversations/{id}`(삭제 시 메시지·질의 로그·피드백 함께), `PUT /messages/{id}/feedback`(덮어쓰기, `reason`), `GET /index/coverage`
- [ ] 첫 질문 시 대화 생성, 제목은 첫 질문 앞 40자
- [ ] 화면: 왼쪽 대화 목록(이름 변경·삭제), 가운데 메시지·입력창과 필터(디렉터리·형식·수정일·로컬 삭제 포함), 오른쪽 출처 패널(접기), 입력창 위 색인 범위 한 줄
- [ ] 출처 항목: 경로(복사 버튼), 위치, 수정일, 인용 구절, 로컬 삭제 표시, 문서 상세 링크, Windows에서만 "폴더에서 보기"(`chanjin-sync://reveal?k=`)
- [ ] 마크다운: react-markdown + remark-gfm, 원시 HTML 끔, 이미지 미렌더링(대체 텍스트), 링크는 텍스트로만, 코드 블록 안 `[n]`은 칩으로 바꾸지 않음
- [ ] 인용 칩(버튼) 클릭 → 출처 패널 해당 항목 열기, 스트리밍 영역 `aria-live`
- [ ] 찾지 못함 응답: 검색 범위와 참고 후보 표시
- [ ] 오류 말풍선: 화면 문구, `retryable`이면 다시 시도
- [ ] 피드백: 좋아요·싫어요, 사유("틀림", "실제로는 문서에 있음", "기타"), 메모
- [ ] 768px 미만에서 대화 목록·출처 패널을 서랍으로
- [ ] 로그: `conversation.created`, `conversation.renamed`, `conversation.deleted`, `feedback.saved`
