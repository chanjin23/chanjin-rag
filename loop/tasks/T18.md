# T18 · (후속) HWP·HWPX·XLSX 파서

> 미뤄 둔 작업입니다. 기본 실행에서는 건너뛰며 `bash scripts/loop.sh --only T18` 또는 `--include-deferred`로만 실행합니다. 실행 전에 실제 HWP·XLSX 샘플 폴더를 `loop/config.json`의 `sample_docs_dirs`에 추가하세요.

## 목표

T04에서 `unsupported_format`으로 남겨 둔 HWP·HWPX·XLSX를 지원한다.

## 근거

- PRD F-04, 9장(HWP 파싱 품질, 표 청킹 리스크), TRD 3.4, 6.3(표 청킹), 13장 4번

## 구현 항목

- [ ] XLSX(openpyxl read-only, data\_only): 시트·행 범위, 첫 비어 있지 않은 행을 헤더로, 계산값 없으면 수식 문자열 + 경고, 표 청킹(T05)과 연결
- [ ] HWPX(zipfile+lxml): `Contents/section*.xml`의 구역·문단·표
- [ ] HWP(pyhwp 계열): 문단 위치, 실패 사유 코드
- [ ] 등록표에서 `unsupported_format` 처리를 걷어내고, 이미 `unsupported_format`으로 실패한 문서를 재처리 대상으로 표시하는 방법 제공
- [ ] 샘플 테스트: 샘플 폴더의 XLSX·HWP·HWPX 성공률(있을 때)
