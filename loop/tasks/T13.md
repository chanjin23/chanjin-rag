# T13 · 동기화 화면: 상태, 범위 설정, 지금 동기화

## 목표

동기화 상태를 보고, 루트·제외 패턴을 안전하게 바꾸고(삭제 미리보기), 웹에서 Agent를 실행하는 흐름을 만든다.

## 근거

- PRD 3장(수집 범위, 서버 데이터 삭제), F-01, F-03, TRD 6.1(대량 삭제 보호), 6.5(범위 제외 삭제), 8.3(`/settings/sync*`, `/sync/status`, `/sync/held-deletions/apply`), 9.1(`/sync`), 9.3(지금 동기화 버튼), 12.4(경고 배지)

## 구현 항목

- [ ] API: `GET·PUT /settings/sync`(루트는 `C:\Chanjin\dev` 하위만, 저장 시 범위 밖 문서 즉시 영구 삭제와 인용 가림), `POST /settings/sync/preview`(삭제될 수와 예시 10개, 저장 안 함), `GET /sync/status`, `POST /sync/held-deletions/apply`
- [ ] 화면: 최근 실행, 대기열, 오늘 임베딩 사용량(x/100), 최근 백업, 보류된 삭제 경고와 적용 버튼, 건너뛴 형식 통계, 하루 넘은 동기화·백업 경고 배지
- [ ] 범위 편집: 고정 제외는 읽기 전용, 저장 전 미리보기 확인 창(삭제 수, 예시, 백업·외부 전송 안내)
- [ ] 지금 동기화: 실행 중이면 버튼 대신 진행 상태, 누르면 `chanjin-sync://run?source=web`, 60초 비활성화, 2초 간격 조회, 30초 안에 새 실행이 없으면 CLI 안내. Windows가 아니면 버튼 숨김. E2E에서는 `page.clock`으로 시간을 제어
- [ ] 로그: `settings.sync.updated`, `settings.sync.previewed`, `sync.held_deletions.applied`, `documents.purged`
