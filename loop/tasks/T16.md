# T16 · 첫 실행 체크리스트, 상태 점검, 전역 배너

## 목표

처음 쓰는 사람이 막히지 않게 체크리스트를 보여주고, 서버·Worker·Provider 이상을 화면 전체 배너로 알린다.

## 근거

- PRD F-18, TRD 7.1(문서 0개면 체크리스트 안내), 8.3(`/setup/status`, `/health`), 9.1(채팅 빈 상태, 공통 화면 상태), 12.4(모니터링)

## 구현 항목

- [ ] `GET /setup/status`: 사용자 존재, 토큰 발급 여부, Agent 첫 접속 시각, 첫 동기화 완료 여부, 문서 수
- [ ] `GET /health`: DB, Worker 하트비트(90초 넘으면 이상), 디스크 여유(10GB 미만 경고), Provider 마지막 성공·실패 시각과 오류 코드(T03 호출 기록 활용)
- [ ] 채팅 화면: 문서가 0개면 빈 화면 대신 체크리스트(각 단계 명령과 완료 표시)
- [ ] 전역 배너: `provider_auth` 오류, Worker 하트비트 끊김, 디스크 부족. 닫아도 상태가 바뀌면 다시 표시
- [ ] 시각 표시: 한국 시간, 하루 이내 상대 시각(공용 유틸로 다른 화면도 사용)
- [ ] 로그: `setup.status.checked`, `health.degraded`

## 범위 밖

- 외부 모니터링 시스템
