# T09 · Hybrid 검색

## 목표

벡터(pgvector)와 BM25(pg\_search)를 SQL 하나에서 RRF로 합치는 검색 함수와 검색 범위(coverage) 계산을 만든다.

## 근거

- PRD 5.2-2, F-07, TRD 5.4(색인), 7.2(SQL, 필터, 문서당 최대 3개), 7.1(검색 범위 `coverage`)

## 구현 항목

- [ ] TRD 7.2 구조의 SQL: 벡터 상위 50 + BM25 상위 50 → RRF(k=60) → 30개. 실제 pg\_search 연산자·함수는 T00의 이미지 버전에 맞춤(어긋나면 TRD 갱신)
- [ ] `hnsw.iterative_scan` 설정
- [ ] 필터: 디렉터리(접두어), 형식, 수정일 범위, `include_deleted`(기본 true)
- [ ] 임베딩 없는 청크는 BM25로만 들어옴
- [ ] 최종 선택 시 문서당 최대 3개
- [ ] `coverage`: 필터 적용 후 `bm25_docs`, `vector_docs`, `pending_docs`, `filters_applied`
- [ ] 결과 항목: 청크 ID, 문서 ID, 경로, 위치, 수정일, 스니펫, `locally_deleted`, RRF 점수와 각 순위
- [ ] 검색 지연을 측정해 반환(질의 로그용)
