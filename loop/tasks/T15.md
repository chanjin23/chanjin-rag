# T15 · 평가 CLI와 평가 화면

## 목표

`rag-eval`로 평가셋을 실행해 PRD 8장 지표를 계산하고 저장하며, 이전 실행과 비교한다. 웹에서 결과를 보고 싫어요 피드백에 실패 유형을 붙인다.

## 근거

- PRD 8장(평가셋 구성, 지표, 실패 사례 기록), F-12, F-13, TRD 5.3(`eval_runs`, `eval_results`, `feedback`), 8.3(`/eval/runs*`), 9.1(`/eval`), 14장(평가 CLI 규칙)

## 구현 항목

- [ ] 평가셋 형식 `eval/datasets/*.yaml`: 문항 ID, 질문, 유형(단일, 종합, 표·슬라이드, 답 없음, HWP), 정답, 근거 `(경로, 위치)` 목록. 예제 데이터셋은 합성 문서 기준으로 만들고 샘플 문서 내용은 넣지 않음
- [ ] 지표: Recall@5, MRR(`(경로, 위치)` 겹침), 근거 충실성·답변 정확도(judge Provider, 정답·부분·오답 = 1·0.5·0), "찾지 못함" 정확도, p95(질의 로그)
- [ ] judge 모델은 답변 모델과 다르게 설정하고 `eval_runs.config`에 기록, 라벨 경로가 `documents`에 없으면 경고 후 제외
- [ ] `rag-eval run`, `rag-eval compare <a> <b>`, 결과는 `eval_runs`·`eval_results`에 저장, 평가 질문 임베딩은 한도 미사용, `query_logs`에 평가 출처 구분
- [ ] `pyproject.toml`의 pytest `testpaths`에 `eval/tests` 추가
- [ ] API·화면: 실행 목록, 지표 표, 이전 실행 대비 증감, 싫어요 피드백 목록과 실패 유형 붙이기(`reviewed_at`)
- [ ] 로그: `eval.run.started`, `eval.run.completed`, `feedback.reviewed`
